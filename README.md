## 📖 Miniguia de Estudo

### O que é Business Intelligence?

Business Intelligence (BI) é o conjunto de processos e tecnologias usados para coletar, organizar e analisar dados, transformando informações em apoio para decisões empresariais.

### Principais etapas do BI

1. Coleta de dados
2. Tratamento e organização
3. Análise
4. Visualização
5. Tomada de decisão

### Dashboards

Dashboards são painéis visuais que reúnem gráficos, indicadores e informações importantes para facilitar a análise de dados.

### KPIs

KPIs são indicadores utilizados para acompanhar o desempenho de objetivos importantes de uma empresa.

Exemplos:

- faturamento;
- lucro;
- ticket médio;
- número de clientes;
- crescimento das vendas.

### Power BI

Power BI é uma ferramenta da Microsoft utilizada para conectar, tratar, analisar e visualizar dados por meio de relatórios e dashboards.

### Cultura Data-Driven

Uma empresa Data-Driven utiliza dados e evidências para apoiar suas decisões, reduzindo a dependência apenas de opiniões ou percepções.

### Exemplo prático

Uma empresa pode utilizar BI para analisar suas vendas por produto, região e período.

Com essas informações, os gestores podem identificar quedas de desempenho, produtos mais vendidos e oportunidades de melhoria.

---

## 📘 Glossário

**Business Intelligence (BI):** conjunto de processos e tecnologias utilizados para transformar dados em informações úteis para a tomada de decisão.

**Dashboard:** painel visual que reúne gráficos, indicadores e outras informações importantes.

**KPI:** indicador utilizado para acompanhar o desempenho de um objetivo ou processo.

**Data-Driven:** abordagem em que decisões são apoiadas por dados e evidências.

**Insight:** conclusão ou descoberta relevante obtida a partir da análise de dados.

**ETL:** processo de extrair, transformar e carregar dados.

**Power BI:** plataforma da Microsoft utilizada para análise e visualização de dados.

**Data Warehouse:** ambiente utilizado para armazenar e organizar dados de diferentes fontes para análise.
